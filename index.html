In Minecraft: Bedrock Edition, script modules inside BP/manifest.json use Semantic Versioning (major.minor.patch) that increments independently of the base game version. When a user selects their Minecraft Bedrock version in BedrockForge Studio, the generator automatically queries the registry below to populate min_engine_version and the exact @minecraft/server and @minecraft/server-ui dependency versions.

⚡ Script API v1 vs. Script API v2 (1.21.90+)

Script API v1.x (Minecraft 1.19.70 – 1.21.80): Uses @minecraft/server 1.0.0 to 1.19.0 and @minecraft/server-ui 1.0.0 to 1.3.0. Custom components are registered inside world.beforeEvents.worldInitialize, and entities/blocks use entity.isValid() as a method.

Script API v2.x (Minecraft 1.21.90 – 1.26.x+): Uses @minecraft/server 2.0.0+ and @minecraft/server-ui 2.0.0+. Scripts execute before the world loads: custom components register in system.beforeEvents.startup, world initialization listens to world.afterEvents.worldLoad, and isValid is now a boolean property instead of a method.

"beta" Wildcard Support (Minecraft 1.21.120+): Creators testing Beta APIs can set "version": "beta" in manifest.json dependencies so the pack automatically uses the latest beta module without manual version bumps each preview.

📁 Standard Bedrock Add-On Folder Architecture

Behavior Pack (_BP.mcpack): Contains server-side logic and data: manifest.json (with data and script modules), pack_icon.png, scripts/main.js, items/*.json, blocks/*.json, entities/*.json, recipes/*.json, functions/*.mcfunction, and texts/en_US.lang.

Resource Pack (_RP.mcpack): Contains client-side visuals and audio: manifest.json (with resources module), pack_icon.png, textures/item_texture.json, textures/terrain_texture.json, textures/items/*.png, textures/blocks/*.png, blocks.json, sounds/sound_definitions.json, and texts/en_US.lang.

Combined Add-On (.mcaddon): Bundles both _BP.mcpack and _RP.mcpack with cross-linked dependencies UUIDs so Minecraft imports and activates both packs together with a single click.
